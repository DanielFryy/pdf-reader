# PDF Reader

## Motivation

This project started from a simple reading problem: local PDF files are easy to open in a browser or a dedicated PDF reader, but they are not always comfortable to read for long stretches.

I wanted something closer to the experience of reading on Scribd with the Dark Reader extension enabled, where a stark black-and-white PDF can become easier on the eyes: a yellow-ish background, dark text, and a warmer dark-mode reading surface.
